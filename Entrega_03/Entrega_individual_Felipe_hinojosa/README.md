# Proceso
###### En primer lugar se intentó hacer un gráfico de barras dobles mediante la base de datos existente, respecto a las altas y bajas por equipo. Con ayuda de Gemini, tutoriales de YouTube y con el conocimiento adquirido en clase, se realizó el script y llegamos al gráfico deseado, sin embargo nos pareció que no entregaba información nueva y relevante que nos permita llegar a conclusiones. Por ello se le agregó a la base de datos una nueva columna con la posición de los equipos en los campeonatos año a año.
###### Gracias a esto pudimos hacer diferentes combinaciones. Hicimos una tabla doble donde veíamos una tabla de cantidad de altas por año y la tabla de posiciones del campeonato, pero no convenció ya que no se veía tan clara. También se hizo un gráfico de líneas para ver la evolución de ambas variables, sin embargo visualmente era muy difícil de comprender a pesar de la simbología.
###### Finalmente, se decidió hacer la tabla de posiciones por año que además muestre una barra de cantidad de altas de cada equipo para así relacionar cuánto jugar nuevo entra a la plantilla con el rendimiento deportivo año por año.

# Base de datos
###### Se cambiaron los años de 2018-2025 a 2019-2026 para así hacerlo coincidir con las fechas de los campeonatos. Además, se agregó una columna con las posiciones de cada equipo en el año correspondiente
