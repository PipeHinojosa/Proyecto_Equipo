# Ficha técnica de la base de datos dinero del fútbol chileno

## Características de los datos

La base de datos corresponde a información cuantitativa relacionada con los montos de dinero recibidos por clubes del fútbol chileno por concepto de derechos de transmisión. Los datos se expresan en pesos chilenos (CLP) y representan la distribución de ingresos entre los clubes considerados en el estudio.

## Variables incorporadas

| Variable        | Descripción                                                                                                        |
| --------------- | ------------------------------------------------------------------------------------------------------------------ |
| Club            | Nombre del club de fútbol que recibe ingresos por derechos de transmisión.                                         |
| Dinero recibido | Monto de dinero recibido por cada club por concepto de derechos de transmisión, expresado en pesos chilenos (CLP). |

## Observaciones sobre la base de datos

La base de datos presenta una distribución desigual de ingresos entre los clubes analizados. Colo Colo, Universidad de Chile y Universidad Católica reciben montos superiores respecto a otros equipos. Además, varios clubes presentan exactamente el mismo monto recibido, por lo que, para facilitar la representación gráfica y el análisis visual, estos fueron agrupados bajo la categoría **"Otros clubes"**.
